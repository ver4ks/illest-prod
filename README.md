# ILLEST

Releases of the ILLEST desktop app. Every release here is built and published by ILLEST's release workflow; nothing is added by hand.

## Download

| | |
|---|---|
| **Windows** | [ILLEST-Setup.exe](https://github.com/n1ssyyy/illest-prod/releases/latest/download/ILLEST-Setup.exe) |
| **macOS, Linux** | The newest release's files, under [Releases](https://github.com/n1ssyyy/illest-prod/releases/latest) |

Or use ILLEST in a browser at [chat.illest.world](https://chat.illest.world).

## Updates

Once installed, ILLEST keeps itself up to date: it checks when it starts and while it runs, and asks before it restarts. Every
update is signed, and the app installs nothing whose signature does not verify.
